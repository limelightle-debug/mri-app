MRI とは

SKEW・VIX・シラーPE（CAPE）の3つについて、いまの値の10年平均からの乖離率が、過去10年の乖離率の平均からどれだけ外れているかを、正規分布の中での位置（パーセンタイル、0〜100）で表し、その3つを平均したものです。平均からの乖離ではなく、乖離の平均からの乖離を見ています。

MRI = ( SKEW + VIX + CAPE ) ÷ 3 × 100

月ごとの値

計算は月単位です。各月の値は、その月の最後の取引日の終値です。CAPE は multpl.com の各月の値を使います。

VIX と SKEW は常用対数（log10）に直してから計算します。CAPE はそのまま使います。以下では、この値を x と書きます。

計算の手順

どの月 t についても、その月を含む直近120か月（10年）を窓にします。

  1. 10年平均
    μt = ( xt−119 + … + xt ) ÷ 120
  2. 乖離率（10年平均から何%離れているか）
    dt = ( xt − μt ) ÷ μt

    過去の各月の乖離率も、それぞれの月を含む120か月の平均で計算した値です。

  3. 乖離率の平均と標準偏差（同じ120か月の d）。乖離率の平均 m がトレンド補正です。指標の水準が一方向に動いていると、乖離率は同じ向きに偏り続けます。その偏りを m で差し引きます。
    mt = ( dt−119 + … + dt ) ÷ 120
    st = dt−119 … dt の標準偏差
    標本標準偏差（n−1 で割る）
  4. 標準化（乖離の平均からの乖離を、乖離の標準偏差で割る）
    zt = ( dt − mt ) ÷ st
  5. パーセンタイルに変換（標準正規分布の累積分布 Φ。z が分布の下から何%の位置にあるか）
    SKEW = Φ( z )
    CAPE = Φ( z )
    VIX = 1 − Φ( z )

    VIX だけは逆向きです。VIX が10年の傾向より低い（楽観が強い）ほど、リスクを高く出します。

  6. MRI = 3つの平均 × 100

Excel の関数でいえば、AVERAGE・STDEV（STDEV.S）・NORMDIST（累積 TRUE）による計算と同じです。

当月の扱い（ローリング計算）

当月の行には、月末を待たずにその日の値（暫定値）を入れて計算します。前月までの119か月は確定した月末値です。

日足チャートの各日は、その日の値を当月の行として計算した MRI です。たとえば2026年10月15日の点は、2016年11月〜2026年9月の119か月の月末値に、10月15日の値を加えた120か月から出しています。月の最後の取引日の値は、その月の月次の MRI と一致します。

日々の CAPE

CAPE は月次の値しか公表されていないため、日々の値は S&P500 の日次終値から次のように計算します。

E10月（10年平均利益）
　= その月の S&P500 平均終値 ÷ その月の CAPE
CAPE日
　= 月初からその日までの S&P500 終値の平均 ÷ E10月

月末の日には、その月の CAPE と一致します。当日の CAPE は multpl.com の最新値をそのまま使います。

過去の日の CAPE は、その月の確定値から逆算した推計です。当時その日に表示されていた値とはわずかに異なることがあります。

CAPE の改定と過去の値への影響

multpl.com は、公表済みの直近の月の CAPE を後から改定します。S&P500 の利益の確定や物価指数の反映によるものです。このアプリは毎回、改定後の最新の値で全期間を計算し直します。

そのため CAPE が改定されると、すでに表示した値も次のように変わります。

  • 改定された月：その月の CAPE、日々の CAPE（E10 が変わるため）、MRI が変わります。
  • その後の月：改定された月の値は、その後120か月の10年平均に入ります。さらにそこで出た乖離率が、その後の乖離率の平均と標準偏差に入ります。このため、改定された月から最長239か月後までの CAPE のリスク値と MRI が少しずつ変わります。
  • それより前の月：改定された月の値を使わないので変わりません。

過去に見た MRI の値と、いまチャートに出る同じ日の値が一致しないことがあるのはこのためです。改定前の値で記録した表とも、改定された月以降でずれていきます。

インジケーターの目盛りの線は、z が ±1σ・±2σ にあたる位置です。

チャートの S&P500

チャートの S&P500 は、株価そのものではなく、トレンド補正後の値です。3指標と同じ計算（月末終値、当月はその日の値、10年の乖離率、乖離率の平均によるトレンド補正、Φ によるパーセンタイル化）で 0〜100 にしたものです。対数はとらず、CAPE と同じく値をそのまま使います。100 に近いほど、株価が10年の傾向から見て上に外れていることを表します。偏差値（50＋10z）ではなく、z を正規分布の中での位置（パーセンタイル）に直した値なので、50 が傾向どおり、84 が +1σ、98 が +2σ にあたります。

MRI も S&P500 も、上がる・下がる確率を表すものではありません。10年の傾向から見て、いまの値がどれだけ外れているかを表します。

チャートは上下2つの欄に分かれていて、それぞれに表示するもの（MRI・SKEW・VIX・CAPE・S&P500）をチェックボックスで選べます。どれも同じ 0〜100 の目盛りです。下の欄で何も選ばなければ、上の欄だけになります。

読むときの注意（構造的な問題）

この計算は、乖離率の平均を差し引くことで、指標の水準のゆるやかな変化（トレンド）を補正しています。ただし、乖離率の平均も過去10年分なので、補正は10年の窓の速さでしか追いつけません。水準が急に変わったときや、暴落が窓に入ったり出たりするときには、トレンド補正をかけても影響は避けられません。指標ごとの事情は次のとおりです。

  • VIX：1990年代・2010年代・2020年代のどれでも、平均はおおむね17〜20です。危機で跳ねても元の水準に戻り、水準そのものの変化がないため、最も信頼できます。
  • SKEW：1990〜2009年は年平均111〜121でほぼ横ばいでした。2013年ごろから上がり始め、2020年代は145〜150前後が普通になっています。水準が上がる局面では乖離率が上向きに偏り続けます。トレンド補正で偏りの一部は差し引かれますが、追いつききれず、リスク値が高めに出ます。
  • CAPE：1990年代前半の17〜20から、2020年代は30台後半まで水準が上がっています。上がり方がゆるやかなので、トレンド補正がある程度効いています。それでも SKEW と同じ種類の問題を持っています。

リーマンショックの影響：2013〜2018年は、CAPE のリスク値が年平均で90を超え続けました。10年平均の中に、2008〜09年に13前後まで下がった CAPE が入っていて、平均が低く引っ張られていたためです。リーマンショック（2008年9月）が10年平均の窓から外れたのは2018年9月、底値（2009年3月）が外れたのは2019年3月です。2011〜2018年に MRI が80を超えた日が多いのは主にこのためで、相場の過熱だけを表しているわけではありません。このため、チャートは2019年1月から表示しています。

乖離率の平均と標準偏差の窓には、危機を含む10年平均で計算した乖離率が2018年まで入っています。影響はずっと小さくなりますが、それが窓から抜けきるのは2028年ごろです。

いつから計算できるか

VIX と SKEW が1990年1月からしかないため、MRI は2009年11月から計算できます。ただし上の理由で、2018年までは機能していないため、表示は2019年1月からにしています。

  • 乖離率を1本出すのに120か月が必要です。最初の乖離率は1999年12月です。
  • その平均と標準偏差を出すのに、乖離率がさらに120本必要です。最初の乖離率から数えて120本目が2009年11月です。
